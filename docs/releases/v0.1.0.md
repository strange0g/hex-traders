# Hex Traders v0.1.0

Initial native Rust source release for three- and four-seat base-game play in fixed
and variable setups. The library handles legal choices, trading, all development
cards, exact Longest Route and Largest Army, and immediate victory. Commands
commit atomically; typed rejections preserve state and randomness. Seat and
spectator projections protect hidden information.

The strict JSON API, private save/resume and deterministic accepted-command replay
use API, snapshot-schema and replay-format version 1. Rules identity is
`hex-traders-base-v1`; RNG identity is `chacha12-rand010-v1`. The package is
`hex-traders-engine` 0.1.0, imported as `hex_traders_engine`, using Rust 1.98.1 and
edition 2024. See the [integration guide](https://github.com/strange0g/hex-traders/blob/v0.1.0/README.md) and
[changelog](https://github.com/strange0g/hex-traders/blob/v0.1.0/CHANGELOG.md).

Native Linux tests and documentation examples verify the engine. Native
performance acceptance remains unresolved: changing CPU clock and turbo policies
prevented a reliable comparison with the retained reference measurements. The
maintainer explicitly approved this initial source release with that uncertainty
recorded as [R01](https://github.com/strange0g/hex-traders/blob/v0.1.0/CONSTRAINTS.md#exceptions).
The 5% manual review policy remains in force; this release does not claim that
its timing gate passed, an absolute budget or a cross-target speed guarantee.

The host supplies identity, private seeds, transport, storage and deduplication.
Browser/Wasm bindings, a user interface, gameplay hosting and package-registry
publication are outside this source release.
