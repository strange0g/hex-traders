# Release verification evidence

The release/ directory records fresh task commands, revisions, outcomes and
limitations. Historical task/checkpoint/performance documents are explicitly
public derivatives; their exact original source/history and indexed evidence are
privately preserved and verified by T35. No original archive, index, specialist
raw report or preparation Git object is part of this release tree.

The export manifest accounts for checked source/tooling files and intentional
private-original exclusions. Its own digest is recorded by the Git commit rather
than recursively embedded in itself. Subsequent task commits identify later file
changes; original export hashes describe the T45 export input, not future HEAD.
